# SAFE - Sistema de Acesso Facial Embarcado

Projeto desenvolvido para a disciplina de Projeto Integrador IV - Arquitetura e Organização de Computadores



---

Para criar, ativar o ambiente virtual e instalar os requisitos: 

### Windows

```
cd software/api

python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install --upgrade pip

pip install -r requirements.txt
```
### Linux
```
sudo apt update

sudo apt install python3-venv python3-pip

cd software/api

python3 -m venv .venv
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```
